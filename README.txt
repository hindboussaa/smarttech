SMART TECH GUIDE — SETUP

1. Open index.html locally to preview.
2. Edit About, Contact and Privacy pages: remove all placeholder text and ensure claims match your actual practices.
3. Review, fact-check, expand and personalize the three starter articles. They are examples, not a guarantee of AdSense approval. Add original articles demonstrating first-hand value.
4. Publish all .html files and style.css in the same folder to a static host (e.g. GitHub Pages or Netlify) and test all links on mobile. A custom domain is optional but useful.
5. Set up Google Search Console, submit a sitemap when available, and ensure pages can be indexed.
6. Before adding analytics/ads, configure an appropriate cookie consent solution where required, especially for UK/EEA visitors.
7. Apply to AdSense when the site is complete and meets program policies. Add AdSense code only as directed by Google after application; do not click your own ads.

No backend, forms, analytics, tracking or ads are included in this starter site.
